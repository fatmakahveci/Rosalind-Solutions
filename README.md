# Rosalind Bioinformatics Solutions

Python solutions to Rosalind problems covering computational biology, string algorithms, graph problems, probability, and sequence alignment.

## Highlights

- One directory per problem for focused navigation
- Problem statements or sample data stored beside solutions
- Classical alignment, motif, graph, and dynamic-programming algorithms
- Implementations ranging from introductory exercises to advanced bioinformatics

## Technology

- Python
- Bioinformatics
- Algorithms

## Getting Started

### Prerequisites

- Python 3
- Any script-specific package noted in its source

### Installation

```bash
git clone https://github.com/fatmakahveci/Rosalind-Solutions.git
cd Rosalind-Solutions/<problem-directory>
python3 <solution>.py
```

Run a solution from its problem directory when it reads the adjacent text file. Input and output conventions follow the linked Rosalind exercise.

## Repository Structure

- Each top-level problem directory contains its Python solution
- Adjacent `.txt` files contain problem text, sample data, or expected output
- Extra algorithm experiments are grouped under directories such as `aho_corasick` and `needleman_wunsch`
